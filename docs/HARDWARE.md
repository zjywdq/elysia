# 硬件与接线

本表以整理后的有效宏定义为准。原源码部分注释保留了旧引脚或旧串口速率，接线时以本表及当前头文件为准。

## ESP32-S3 主控

| 功能 | 信号 | GPIO |
| --- | --- | --- |
| INMP441 麦克风 | BCLK | 4 |
| INMP441 麦克风 | WS | 5 |
| INMP441 麦克风 | SD | 6 |
| I2S 扬声器 | BCLK | 9 |
| I2S 扬声器 | LRC/WS | 10 |
| I2S 扬声器 | DIN（主控 DOUT） | 11 |
| UART 音频转发 | TX | 39 |
| UART 音频转发 | RX | 40 |
| 蓝牙连接状态输入 | 输入 | 38 |

麦克风 L/R 接地，读取左声道；I2S 使用 32 位立体声槽，取左侧有效数据转为 16 位 PCM。上行采样率为 16 kHz，本地扬声器播放 48 kHz、16 位单声道 PCM。

## 经典 ESP32 蓝牙板

| 功能 | 信号 | GPIO |
| --- | --- | --- |
| UART 音频输入 | RX | 16 |
| UART | TX | 17 |
| 蓝牙连接状态 | 输出 | 5 |

两板连接：

| ESP32-S3 | 经典 ESP32 |
| --- | --- |
| GPIO39 TX | GPIO16 RX |
| GPIO40 RX | GPIO17 TX |
| GPIO38 状态输入 | GPIO5 状态输出 |
| GND | GND |

UART 为 **1,000,000 baud、8N1、无硬件流控**。主控将 48 kHz 单声道 PCM 重采样为 44.1 kHz 单声道，蓝牙端复制左右声道后送 A2DP。连接状态高电平表示已连接，低电平表示未连接。

信号使用 3.3 V 电平并共地。GPIO5 为经典 ESP32 的启动配置引脚，源码已对启动时的状态抖动做防抖处理。GPIO16/17 是否可用取决于具体 ESP32 模组，带 PSRAM 的模组可能占用它们，实际接线前核对开发板引脚图。

原主控配置为 ESP32-S3、16 MB Flash、八线 PSRAM；原蓝牙板配置为 ESP32、2 MB Flash。`sdkconfig.defaults` 保留了这两份实际配置。修改开发板时同步调整 Flash、PSRAM 和分区设置。
