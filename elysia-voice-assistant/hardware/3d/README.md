检查结果：二进制 STL，共 1,494 个三角面；文件长度与面数一致，坐标为有限数，所有几何边均由两个三角面共享。该检查未包含切片、壁厚或实际打印验证。

模型在 X / Y / Z 方向的坐标跨度约为 **287.090 / 62.000 / 140.875**。STL 本身没有编码尺寸单位，导入切片软件时使用原建模软件的单位设置。

GitHub 可以预览此 STL；本地也可用已有 CAD 或切片软件打开。完整 SHA-256 在上一级 `asset-manifest.json` 中。
