# 硬件设计资料

| 目录 | 内容 |
| --- | --- |
| [3d](3d/README.md) | 外壳 STL，适用于三维查看和切片软件 |
| [pcb](pcb/README.md) | 嘉立创 EDA 专业版工程、便携备份、原理图和 PCB 预览 |
| [asset-manifest.json](asset-manifest.json) | 文件校验值、STL 检查结果及工程快照说明 |

模型来自用户提供的 `外壳.STL`，PCB 来自 `lceda-pro` 目录下的“record me”工程。保留设计资料及相关预览，不包含 EDA 安装程序或软件运行库。

原始输入保持不变。当前工程通过 SQLite 只读备份生成一致快照，公开副本仅清除账号密码及用户偏好字段、通用账号显示名；设计、图片、元件及历史数据保持一致。已有 `.epro2` 备份按原文件字节保留。

这些资料尚未进行实物装配、打印适配、PCB DRC 或生产文件验证。固件的有效引脚说明仍以 [接线文档](../docs/HARDWARE.md) 为准，装配时核对图纸与实际固件配置。
